# Smart Scraper M2M API (Free Public Beta)
> A fast, lightweight M2M endpoint designed for Autonomous AI Agents (CrewAI, LangChain, AutoGen) to extract structured JSON from any URL.
API for AI Agents to scrape any web page and receive clean JSON data.

## Base URL
`https://smart-scraper-m2m.vercel.app/scrape`

## Request Format
POST Request with JSON body:
{
  "url": "https://example.com"
}
